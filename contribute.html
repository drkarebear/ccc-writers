How It Works

  1. You send the listing.
    Give us the basics plus an official college, journal, event, or university source.
  2. The source gets checked.
    Dates, eligibility, URLs, and other details are verified before the public data changes.
  3. The listing is added or corrected.
    Approved information is published to the directory, map, submission finder, event board, or pathway page.
  4. The verification date stays visible.
    Students can see how recently the information was checked instead of assuming an old deadline is current.

What Counts as a Source?

Whenever possible, use an official college page, journal website, official submission page, university program page, or official event page.

Social media can help us find something, but it should not be the only evidence for a lasting directory entry when a more stable source exists.

Privacy + Moderation

No Public Accounts

Contributors should not need to make a CCC Writers account or create a public profile.

Minimal Personal Information

A name or email can be optional for follow-up and should never be displayed with the listing unless someone explicitly asks for that.

No Instant Publishing

Community submissions go into a review queue. This prevents spam, stale dates, and accidental misinformation from appearing on the site.

Please Don’t Send

Student ID numbers, private student information, unpublished student manuscripts, passwords, personal phone numbers, or anything that does not need to become part of a public statewide directory.

Report an Accessibility Issue

If something on CCC Writers creates a barrier, email an accessibility report directly. The link can include the page address automatically; browser, device, or assistive technology information is optional.
