Accessibility

Access should not depend on the interface.

CCC Writers aims to meet WCAG 2.2 Level AA and to make the same information available even when an interactive feature is not useful or accessible to a visitor.

Accessibility approach

  • Semantic headings and landmarks organize pages.
  • Keyboard focus is visible and interactive controls are designed for keyboard use.
  • Color is not the only way status or meaning is communicated.
  • The literary journal map is optional; the complete journal information is also available in a searchable list.
  • Forms and filters use visible labels and live result counts where helpful.
  • Images use text alternatives when they communicate information; decorative brand images use empty alt text.
  • Pages are designed to reflow on smaller screens and respect reduced-motion preferences.

Report an accessibility barrier

If something prevents you from accessing information or completing a task, please report the accessibility issue by email. The email link includes the current page address automatically when JavaScript is available.

If you are comfortable sharing it, tell me what you were trying to do and what barrier you encountered. Browser, device, and assistive technology information are optional.

Need the information another way?

You can also use the same email address to request information from this site in a more accessible format.

Ongoing review

Accessibility is treated as an ongoing maintenance responsibility, not a one-time checklist. Community corrections are welcome.
